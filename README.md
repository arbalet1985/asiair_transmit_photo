# asiair_transmit_photo

Две программы для удалённой обсерватории: снимки с **ASIAIR** автоматически передаются на ваш компьютер через интернет, а ненужные снимки можно удалять на ASIAIR с веб-страницы.

```
 Обсерватория (локальная сеть)                    Интернет                Дом
┌─────────┐   SMB (гость)   ┌──────────────────┐   HTTPS, лимит скорости  ┌─────────────────────┐
│ ASIAIR  │ ◄────────────── │ asiair-agent.exe │ ───────────────────────► │ asiair-receiver.exe │
│         │   удаление      │ (трей / служба)  │ ◄─── команды удаления ── │ + веб-страница      │
└─────────┘                 └──────────────────┘                          └─────────────────────┘
```

* **asiair-agent** работает на ПК в той же сети, что и ASIAIR. У него есть окно со значком в трее, автозагрузкой и запуском в свёрнутом виде, а ещё он может работать службой Windows. Он регулярно обходит шары ASIAIR, находит новые снимки и отправляет их приёмнику. Соединение всегда исходящее, поэтому в обсерватории не нужно открывать порты.
* **asiair-receiver** работает на компьютере, куда складываются снимки. Он принимает файлы и показывает веб-страницу со списком снимков, где их можно отметить и удалить на ASIAIR.

Обе программы собираются в один `.exe` без зависимостей и могут работать службой Windows.

## Нужен ли логин и пароль к ASIAIR?

**Обычно нет.** ASIAIR открывает свою память по SMB как общую папку `\\<IP>\EMMC Images` (флешка — `\\<IP>\Udisk`) с **гостевым доступом**. Поэтому агент:

1. Если логин не задан, входит как гость (`guest` без пароля). Если гостя не пускает, пробует `.` / `123456789`: этот вариант работает на некоторых прошивках.
2. Если логин задан в настройках или в ссылке (`smb://логин:пароль@IP/EMMC Images`), использует его.

Проверить подключение можно командой `asiair-agent check`: она покажет, как удалось войти и сколько файлов найдено.

> Обходить корень `\\IP\` у ASIAIR нельзя, нужно обращаться сразу к шаре. Агент так и делает. Windows 11 может блокировать гостевой вход в *Проводнике*, но агента это не касается: у него свой SMB-клиент.

## Возможности

* Ссылка на ASIAIR в любом виде: `192.168.1.50`, `\\192.168.1.50\EMMC Images`, `smb://…`, `dir:Z:\` (уже подключённый диск).
* Передаются только готовые файлы: файл уходит, когда перестал меняться (`min_file_age`), поэтому недописанный кадр не отправится.
* **Ограничение скорости** (`max_rate`: `2MB/s`, `10Mbit/s`, `0` = без ограничения). Лимит общий на передачу, и его можно менять на лету с веб-страницы приёмника.
* **Докачка:** при обрыве связи передача продолжается с того места, где остановилась.
* **Проверка целостности:** SHA-256 всего файла. Файл появляется в папке назначения только после успешной проверки.
* Структура папок ASIAIR сохраняется (`EMMC Images/Autorun/Light/M31/…`), и дата изменения файла тоже.
* Повторно файлы не передаются, в том числе после перезапуска (`agent-state.json`).
* **Удаление на ASIAIR с конечного хоста:** на веб-странице отмечаете файлы или целые папки и нажимаете «Удалить на ASIAIR». Можно сразу удалить и локальную копию. Команда выполняется при следующей связи с агентом, результат виден на странице.
* Защита: HTTPS с самоподписанным сертификатом, который агент проверяет по отпечатку, плюс секретный токен. Веб-страница по умолчанию доступна только с самого компьютера (127.0.0.1), при желании можно закрыть её паролем.

## Сборка

Нужен Go 1.22+.

```sh
./build.sh          # Linux/macOS → dist/*.exe и бинарники для Linux
build.cmd           # Windows     → dist\*.exe
```

Или вручную: `GOOS=windows GOARCH=amd64 go build -o asiair-agent.exe ./cmd/asiair-agent`.

## Установка

### 1. Домашний компьютер (приёмник)

1. Положите `asiair-receiver.exe` в папку, например `C:\ASIAIR-Receiver\`, и запустите двойным щелчком. Приёмник спрячется в трей (значок-телескоп). Щелчок по значку открывает страницу, в его меню есть «Выход».
2. При первом запуске программа сама создаст `receiver.yaml` со случайным токеном и откроет в браузере страницу http://127.0.0.1:8080.
3. На странице:
   * **«Папка для снимков» → «Изменить…»:** выберите диск и папку (можно создать новую) или впишите путь вручную. Настройка сохраняется и применяется сразу.
   * **«Подключение агента»:** здесь токен (кнопки «Показать» и «Копировать») и отпечаток сертификата. Они понадобятся в окне агента. Кнопка «Новый…» заменяет токен: старый сразу перестаёт работать, и новый нужно ввести в агенте.
   * **«Запуск на этом компьютере»:**
     * галочка «Запускать при входе в Windows» запускает приёмник значком в трее при входе в систему. Права администратора не нужны;
     * кнопка «Установить как службу Windows…» ставит приёмник службой: он будет работать сразу после включения компьютера, даже если никто не вошёл в систему. Windows попросит подтвердить права администратора, после этого приёмник сам переключится на службу, а страница обновится. Запуск при входе при этом отключается: служба его заменяет;
     * кнопка «Удалить службу…» убирает службу. Приёмник останавливается; снова запустить его можно двойным щелчком по `asiair-receiver.exe`.
4. Откройте порт `8443` для доступа из интернета:
   * пробросьте его на роутере на этот компьютер (или используйте VPN: Tailscale, ZeroTier);
   * разрешите входящие соединения на 8443 в брандмауэре Windows.

То же самое можно сделать из командной строки от имени администратора: `asiair-receiver.exe install` и `asiair-receiver.exe start`. Режим службы и режим трея одновременно не работают: запуск второй копии просто откроет страницу уже работающей.

### 2. ПК в обсерватории (агент)

1. Положите `asiair-agent.exe` в папку, например `C:\ASIAIR-Agent\`.
2. Запустите его двойным щелчком. Откроется окно агента на вкладке **«Настройки»**.
3. Заполните форму:
   * **ASIAIR → Сетевой путь:** `\\192.168.1.50\EMMC Images` или просто IP. Логин и пароль обычно не нужны. Кнопка **«Проверить»** подключается к ASIAIR и показывает, как удалось войти (гостем или по логину) и какие шары доступны.
   * **Приёмник → Адрес и Порт:** внешний IP или имя домашнего компьютера и порт (по умолчанию 8443). **Токен** — тот же, что в `receiver.yaml`. Кнопка **«Проверить»** соединяется с приёмником. При первой проверке она показывает отпечаток сертификата: сверьте его с веб-страницей приёмника и подтвердите. После этого поле «Отпечаток» заполнится само, а проверка покажет, подходят ли токен и сертификат.
4. Нажмите **«Сохранить и применить»**. Настройки запишутся в `agent.yaml` (остальные параметры и комментарии в файле сохраняются), и агент перезапустится.

Остальные параметры (лимит скорости, фильтры файлов, интервалы) доступны по кнопке «Файл настроек…».

Вкладки окна агента:

* **Состояние:** связь с ASIAIR и приёмником, текущий файл с прогрессом, скорость и лимит, очередь, ошибки и журнал.
* **Настройки:** форма подключения с кнопками проверки и галочки запуска.
* **«Запускать автоматически при входе в Windows (автозагрузка)»:** программа прописывается в автозагрузку текущего пользователя (`HKCU\…\Run`). Права администратора не нужны.
* **«Запускать свёрнутым в трей»:** при запуске окно не показывается, виден только значок в трее.
* Кнопки: «Перезапустить агент», «Открыть журнал», «Свернуть в трей», «Выход».

Кнопки «Свернуть» и «Закрыть» (✕) убирают окно в трей, агент продолжает работать. Окно открывается щелчком по значку в трее или повторным запуском `.exe`. Правый щелчок по значку открывает меню «Открыть окно / Настройки / Перезапустить агент / Выход». Цвет значка показывает состояние: зелёный — на связи, синий — идёт передача, красный — нет связи, серый — ошибка в настройках.

Автозагрузка срабатывает при входе пользователя в Windows. Если ПК в обсерватории перезагружается без входа, используйте вместо окна **службу** (от имени администратора):

```
asiair-agent.exe install
asiair-agent.exe start
```

Окно и служба одновременно не работают: при запущенной службе окно сообщит об этом и не станет запускать второго агента. Проверить связь из командной строки можно командой `asiair-agent.exe check`.

Службы запускаются автоматически вместе с Windows и перезапускаются при сбое. Журнал пишется в `*.log` рядом с `.exe`.

### Команды

| Команда | Действие |
|---|---|
| `gui` | окно (агент) или значок в трее (приёмник); в Windows это режим по умолчанию |
| `run` | запуск в консоли |
| `install` / `uninstall` | установить / удалить службу |
| `start` / `stop` / `restart` / `status` | управление службой |
| `-config путь.yaml` | другой файл настроек (по умолчанию рядом с `.exe`) |
| `asiair-agent check` | проверить связь с ASIAIR и приёмником |
| `asiair-receiver token` | сгенерировать токен (обычно не нужно: создаётся при первом запуске) |
| `asiair-receiver fingerprint` | показать отпечаток сертификата |

## Как это работает

* Агент раз в `scan_interval` обходит шары ASIAIR (по умолчанию пропуская `Thumbnail`) и отправляет приёмнику список файлов: так страница показывает, что лежит на ASIAIR.
* Новые файлы передаются по очереди, от старых к новым: `PUT /api/upload` с указанием смещения, затем `POST /api/commit` с SHA-256. Если связь оборвалась, агент спрашивает у приёмника, сколько байт уже получено (`HEAD`), и продолжает с этого места.
* Раз в `poll_interval` агент отправляет своё состояние (текущий файл, скорость, очередь) и получает команды удаления и лимит скорости. Результат каждого удаления сообщается обратно.
* Незаконченные передачи хранятся в `dest_dir/.partial/`.

## Разработка

```sh
go test ./...
```

Тесты проверяют разбор ссылок и скоростей, ограничитель скорости, докачку и проверку контрольной суммы, а также полный цикл агент → приёмник → удаление на ASIAIR (на локальной папке вместо SMB). Работа через SMB проверялась на Samba с гостевой шарой `EMMC Images`, настроенной как на ASIAIR. Окно агента проверялось в Wine.

Иконка и манифест Windows (нужен окну: Common Controls v6, DPI) лежат в `cmd/asiair-agent/rsrc_windows_*.syso`. Пересоздать их можно командой из `cmd/asiair-agent/gui_windows.go` (`go generate`, запускать без `GOOS=windows`).
