Папка для снимков

—
Структура папок ASIAIR сохраняется внутри этой папки. Уже полученные снимки при смене папки остаются на старом месте.

Место на диске

—
Оставлять свободным
Когда свободного места на диске со снимками остаётся меньше этого запаса, приёмник перестаёт принимать файлы, а агент встаёт на паузу. Снимки на ASIAIR при этом не удаляются, недокачанный файл потом продолжится с того же места. Можно указать процент диска (5%) или объём (10GB, 500MB); 0 — без запаса.

Запуск на этом компьютере

Сейчас приёмник работает
—
Права администратора не нужны. Приёмник стартует, когда вы входите в Windows.
Служба работает сразу после включения компьютера, даже если никто не вошёл в Windows. Windows попросит подтвердить права администратора; после этого приёмник сам переключится на службу, а страница обновится.

На GitHub
—
Приёмник раз в 6 часов проверяет релизы на GitHub. Новую версию он ставит себе сам и перезапускается (служба — через 30 секунд), а агенту передаёт её при следующей связи: агент обновляется и перезапускается тоже сам. Передача снимков после перезапуска продолжается с того же места.
